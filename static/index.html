Welcome

This is a beginner’s guide to no-code automation built around irregular schedules — night shifts, rotating rosters, overtime, and shift swaps — not 9-to-5 routines. Sort your email automatically, set reminders tied to your next shift, track shift swaps, and organize shift paperwork — using tools you already have and tiny scripts you can read end to end.

No programming experience needed. If you can copy and paste, you can use this manual. Plain English, step by step, never condescending.
