# Overview

Welcome to No-Code Automation for Shift Workers. This is a beginner's guide to
safe automation built around irregular schedules — night shifts, rotating
rosters, overtime, and shift swaps — not 9-to-5 routines.

You don't need to be a programmer. You don't need to have used the command
line before. If you can copy and paste, you can use this manual.

It's written for anyone whose day revolves around a roster: organizing shift
paperwork, sorting incoming email automatically, getting reminders tied to
your next shift (not to Monday at 9 AM), and keeping track of shift swaps.
Plain English, step by step, never condescending.

## What's in the manual

| Guide | What it does |
|-------|-------------|
| [Safety first](safety.md) | The rules to follow before you automate anything |
| [Email rules](email-rules.md) | Sort incoming mail automatically — Gmail, Outlook, Apple Mail |
| [Calendar reminders](calendar-reminders.md) | Reminders tied to shifts, appointments, bills, due dates |
| [Shift-swap tracking](shift-swap-tracking.md) | Track swaps, approvals, and who owes whom |
| [File organization](file-organization.md) | Sort shift paperwork into folders |

Each guide with a script has a matching script in `scripts/`. Every script
defaults to a non-destructive preview (dry-run) and works on copies by
default; none touches your originals unless you explicitly ask.

## Printable planner

There's a printable automation planner in `static/planner.html` built for
shift work: shift blocks (day / evening / night / off), a swap tracker, and a
weekly check-in. Open it in your browser and print it (Letter size) to fill
in by hand.
